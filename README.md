# 따릉이 순유출 예측 기반 선제 재배치 제안

2026-2 기계학습기초 팀 프로젝트 (5조)

## 1. 프로젝트 개요

서울 따릉이는 대여소 간 자전거 쏠림이 크지만 재배치 인력은 한정되어 있다.
이 프로젝트는 공개 대여이력으로 **대여소·시간 블록별 순유출(대여 건수 − 반납 건수)** 을 회귀로 예측하고,
곧 비거나 넘칠 대여소를 미리 찾아 순회 우선순위와 마일리지 대상 후보를 제안하는 것을 목표로 한다.

- 문제 유형: 지도학습, 회귀
- 비교 모델: 단순 기준선(지난주 같은 요일·블록 값), Ridge 회귀, Random Forest, LightGBM, MLP(가산점)
- 분할: 시간순 분할(학습 → 검증 → 테스트). 랜덤 분할은 미래 정보가 새어 들어가 사용하지 않는다.
- 평가 지표: RMSE, MAE, R²
- 활용 검증: 예측 순유출 상위 k개 대여소와 테스트 기간 실제 상위 k개의 일치율(Precision@k)

## 2. 데이터와 출처

공개 데이터만 사용한다. 생년·성별·이용자종류 컬럼은 사용하지 않고 대여소 단위로 집계한다.

| 데이터 | 출처 | 라이선스 | 다운로드일 |
|---|---|---|---|
| 따릉이 대여이력 (2025.7~2026.6, 최근 12개월) | [서울 열린데이터광장 OA-15182](https://data.seoul.go.kr/dataList/OA-15182/F/1/datasetView.do) | 공공누리 1유형 | (입력) |
| 대여소 정보: 위치(위경도), 거치대 수 (따릉이 실시간 대여정보 API) | [서울 열린데이터광장 OA-15493](https://data.seoul.go.kr/dataList/OA-15493/A/1/datasetView.do) | 공공누리 1유형 | (입력) |
| 기상(기온, 강수량, 풍속) | 기상청 기상자료개방포털 (선정 예정) | (확인 후 입력) | (입력) |
| 공휴일 | (선정 예정) | (확인 후 입력) | (입력) |

> 실시간 대여정보는 호출 시점의 스냅샷이다. 대여소 속성(거치대 수, 위경도)만 사용하고,
> 호출 시점의 보유 대수와 거치율은 예측에 사용하지 않는다.

## 3. 폴더 구조

```
.
├─ README.md
├─ requirements.txt
├─ .env.example        인증키 형식 예시 (실제 키 없음)
├─ proposal/           제안서
├─ src/                전처리·모델 코드
├─ notebooks/          EDA, 시각화
├─ data/
│   ├─ raw/            원본 데이터 (git에 올리지 않음)
│   ├─ processed/      집계 결과 (git에 올리지 않음)
│   └─ reference/      작은 보조 파일 (공휴일 목록 등)
└─ results/            그림, 지표 표
```

## 4. 재현 방법

1. 패키지 설치
   ```bash
   pip install -r requirements.txt
   ```
2. 인증키 설정: 서울 열린데이터광장에서 인증키를 발급받고, `.env.example`을 복사해 `.env`로 만든 뒤 키를 입력한다.
3. 원본 데이터를 받아 `data/raw/`에 둔다. 파일 이름과 기간은 아래 표에 기록한다.

   | 파일 | 기간 | 비고 |
   |---|---|---|
   | (입력: 2025년 대여이력 중 7~12월분) | 2025.7~2025.12 | 연별 파일에서 해당 월만 사용 |
   | (입력: 2026년 월별 파일) | 2026.1~2026.6 | |

4. 아래 순서로 실행한다. (코드 작성 후 갱신)
   ```bash
   python src/01_fetch_api.py      # 대여소 정보 API 수집
   python src/02_clean.py          # 정제
   python src/03_aggregate.py      # 대여소×시간 블록 집계, 순유출 계산
   python src/04_features.py       # 피처 생성
   ```

## 7. 한계

- 공개 데이터에는 대여소별 재고가 없어, 순유출을 부족·과잉의 간접 지표로 사용한다.
